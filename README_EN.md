# Spira spectrograms: script and figures (chapter 4 of the thesis)

Script and figures of waveforms and mel spectrograms generated from two recordings of the public SPIRA project dataset.

This repository accompanies my doctoral thesis, *Tecnografias de um centro de inteligência artificial: seguindo cientistas e engenheiros universidade afora* (*Technographies of an artificial intelligence center: following scientists and engineers across the university*), Graduate Program in Social Sciences, Institute of Philosophy and Human Sciences, University of Campinas (Unicamp), 2026, supervised by Maria Suely Kofes.

The main documentation is in Portuguese, the language of the research: [`README.md`](README.md) explains the purpose, the method and how to rerun the analyses, and [`docs/USO_NA_TESE.md`](docs/USO_NA_TESE.md) links each figure in the thesis to its script and source data. This file is a short English guide.

## Research data deposit

This repository is part of the dataset *Ethnography of an artificial intelligence center: data and scripts*, deposited in the Unicamp Research Data Repository (REDU).

Not included in the REDU deposit, and where to obtain it:

- The source recordings are not in this folder; they are in the tecno-etnografia-tese-site/audio/ folder of this same dataset and in the public SPIRA dataset (https://github.com/SPIRA-COVID19/SPIRA-ACL2021). Provenance is in audios/README.md.
